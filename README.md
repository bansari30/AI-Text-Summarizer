# AI Text Summarizer

A web app that summarizes long texts into a short version using AI.

Built with AI-assisted development (vibe coding) and the Hugging Face API.

## Features
- Paste a text and get a short summary
- Simple, responsive single-page interface
- [Add any other feature you built]

## Tech stack
HTML, CSS, JavaScript · Hugging Face Inference API

## How to run
1. Download or clone this repository.
2. Create a free API token on Hugging Face.
3. Open `AI-Text-Summarizer.html` and replace `YOUR_API_KEY` with your token.
4. Open the file in your browser.
